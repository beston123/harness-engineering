# Behavioral Guidelines

Follow the guidelines below when writing, reviewing, or refactoring code.

## 1. Think Before Coding

**Don't assume. Don't hide confusion. Surface tradeoffs.**

## 2. Simplicity First

**Minimum code that solves the problem. Nothing speculative.**

## 3. Surgical Changes

**Touch only what you must. Clean up only your own mess.**

## 4. Goal-Driven Execution

**Define success criteria. Loop until verified.**

# Work Guidelines

- **Commit Specification**: Follow the AngularJS Git commit convention.
- **Language Preference**: Always reply in the language used by the user (English by default).
